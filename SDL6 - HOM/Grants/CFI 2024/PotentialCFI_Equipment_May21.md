## Context
Broader CPDD (Centre for Preclinical Drug Discovery) facility infrastructure request across four cores. SDL-HOM equipment sits within Core 1.

> [!INFO] HOM SDL Position in CPDD
> HOM SDL is the biological screening endpoint of the larger CPDD infrastructure network. Core 1 (formulation) is the upstream nanomedicine production step; HOM SDL screens downstream — this pipeline context supports the "no platform couples formulation with autonomous biological screening" claim.

## Facility Cores

| Core | Focus |
|---|---|
| Core 1 | Formulation and In Vitro Assessment (GLP/cGMP-ready) |
| Core 2 | Pharmaceutical Analysis (LC-MS, confocal, UHPLC) |
| Core 3 | In Vivo Assessment (animal facilities, telemetry, PK/tox) |
| Core 4 | In Silico Analysis (AI/ML, real-world evidence datasets) |
