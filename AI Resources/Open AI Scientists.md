# Open AI Scientists

An open-science academic research initiative from the **Zitnik Lab at Harvard Medical School** building autonomous AI systems that conduct scientific research alongside humans.

**Website:** [openscientist.ai](https://www.openscientist.ai/)

## Key Tools
- **Medea** — omics data analysis agent
- **TxAgent** — therapeutic reasoning agent
- **ToolUniverse** — 1,000+ scientific tools accessible to agents

## What Makes it Different
- Fully academic, open-science (not a startup)
- Focus on biomedicine and clinical research
- Agents can autonomously generate hypotheses and run experiments
