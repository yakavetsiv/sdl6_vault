# Skill Curator

A system or tool for organizing, curating, and managing AI agent skills — keeping a searchable library of reusable capabilities.

**Source:** [@neural_avb](https://x.com/neural_avb/status/2053873358853591435)

## Why Curation Matters
- Agents work better with a clean, non-overlapping skill set
- Reusable skills reduce prompt complexity
- A curator can auto-select the right skill for a task
