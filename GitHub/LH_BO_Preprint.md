## Description
Preprint manuscript: "Resource-efficient Bayesian optimization for self-driving liquid handling." Closed-loop calibration framework using qNEHVI multi-objective BO across 5 liquids (water, DMSO, PVA-DMSO, 4% alginate, 100% glycerol) on North Robotics N9 (gravimetric) and Hamilton STARlet (spectroscopic). Cross-platform validation, SHAP parameter importance, human/robot reproducibility benchmark.
