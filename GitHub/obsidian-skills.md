# obsidian-skills

**URL:** https://github.com/kepano/obsidian-skills  
**Author:** kepano (Steph Ango — Obsidian CEO)  
**Language:** —  
**Description:** Agent skills for Obsidian. Teach your agent to use Markdown, Bases, JSON Canvas, and use the CLI.

## Skills Provided
- `obsidian-markdown` — Create/edit files with wikilinks, embeds, callouts, Obsidian syntax
- `obsidian-bases` — Database-style notes with views, filters, formulas
- `json-canvas` — Visual canvas files with nodes, edges, connections
- `obsidian-cli` — Vault interaction for plugin/theme development
- `defuddle` — Extract clean markdown from web pages

## Installation
```bash
npx skills install kepano/obsidian-skills
```
