# Changes Resulting from Increase in Minimum Wage Rates

From: [The Division of People Strategy, Equity & Culture](https://people.utoronto.ca/author/hreadmin/); Central Payroll Services & HRIS Support Team

On October 1, 2023, minimum wage rates in Ontario will increase in accordance with the changes in the [*Employment Standards Act (ESA)*](https://www.ontario.ca/page/minimum-wage-increase).

As a result, please note the following specific wage increases which will be implemented in HRIS and attendance systems (i.e. Kronos) effective October 1, 2023:

**a. Bargaining unit: USW Local 1998 (Casual)**

|  |  |  |
| --- | --- | --- |
| **Classification** | **Previous Minimum Rate** | **Revised Minimum Rate as of** **October 1, 2023** |
| USW Casual | $15.50 | $16.55 |

**b.** **Work Study Students**

|  |  |  |
| --- | --- | --- |
| **Classification** | **Previous Minimum Rate** | **Revised Minimum Rate as of** **October 1, 2023** |
| Casual Work Study Biweekly | $15.90 | $16.55 |
| Casual Work Study Monthly | $15.90 | $16.55 |

**Questions about these changes?**

For questions about work study wage rate, please contact the University Registrar’s Office at workstudy@utoronto.ca.

If you have processing or payroll-related questions, please contact the HRIS Support Team or Central Payroll Services using [Get Help on the HR Service Centre](https://uthrprod.service-now.com/esc?id=sc_cat_item_guide&sys_id=bc53487d1bfd8890d57786e9cd4bcb5d&sysparm_category=abc78de49f331200d9011977677fcfb2).
