# Updates on central automation for ATB increase

From: [The Division of People Strategy, Equity & Culture](https://people.utoronto.ca/author/hreadmin/)

|  |  |
| --- | --- |
| Date | July 9, 2018 |
| To: | Business Officers (via the AMS listserv); Divisional HR Offices |
| From: | HRIS Support Team, Division of Human Resources & Equity |
| Re: | **For information and action: Updates on central automation for ATB increase** |

---

Further to the June 25 message regarding the across-the-board (ATB) increase for the PM / Confidential / RA/SRA and USW employee groups, the applicable increases have been processed centrally in HRIS.

This means that IT 9009 Appointment Details and IT 0008 Basic Pay were updated with effective date July 1, 2018, **excluding the exceptions as listed on the ‘ATB Update and Exception Report’.**

## Next steps

**By July 20 Monthly Pay Close:**

1. Run the applicable ATB Update and Exception Report to review which employee records have been processed centrally and which employee records need manual updates – these records included the increase that are already manually updated, the message does not reflect the manual update status.
2. Run the [Basic Pay Report](http://dlrssywz8ozqw.cloudfront.net/wp-content/uploads/sites/31/2016/04/Proc-12-15-BASIC-PAY-REPORT.pdf) for your organizational unit to verify the updated salary in IT 0008.
3. Run the [HR Data Verification Report](http://dlrssywz8ozqw.cloudfront.net/wp-content/uploads/sites/31/2016/06/Ref-1-25-DATA-VERIFICATION-REPORT.pdf) for your organizational unit to check inconsistent data.
4. On-line the ATB increase in HRIS for employees who are listed as an exception and require manual update on both IT 9009 Appointment Details & IT 0008 Basic Pay.

## Support

Regarding the processing of the ATB increase in HRIS, please feel free to contact the HRIS Help Desk using the [AMS Help Form](http://sites.utoronto.ca/ams/help.htm).

If you are planning to attend the ATB Get Help Fast Session on July 16, 2018, 10 a.m. – 4 p.m. at AMS 256 McCaul Training Rm 103, please register via email at hris.help@utoronto.ca.

Questions with respect to the increase eligibility should be directed to [your Divisional HR Office](http://staff.hrandequity.utoronto.ca/#div_off).
