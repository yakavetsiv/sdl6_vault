## Core Manuscript Claim

The ExNode paper should be positioned as an execution-layer contribution:

> Existing self-driving laboratory frameworks describe planning, orchestration, optimization, or device communication, but they often leave device-level execution authority, state validation, resource locking, and safe coexistence with vendor software underspecified.

The bibliography supports this claim through four clusters:

1. SDL motivation and scaling pressure: [[02 Self-Driving Laboratory Context]]
2. Workflow/orchestration systems: [[03 Orchestration and Workflow Systems]]
3. Device integration and communication standards: [[04 Device Integration and Protocol Interfaces]]
4. Safety, state, scheduling, and agent boundaries: [[05 Execution Safety State and Scheduling]] and [[06 AI Agents and AI-Assisted Development]]
